# Projekt: Automatyzacja Testów Mobilnych (Appium + Python)

## O projekcie
Repozytorium zawiera skrypty i konfiguracje stworzone podczas laboratorium "Testowanie aplikacji mobilnych".

## Technologie
* Python, Pytest, Appium, Requests, Docker, Allure Report

## Opis zrealizowanych bloków
* **Blok 1-2:** Środowisko, Git, ADB, Analiza APK.
* **Blok 3-4:** Docker, Appium Server, Lokalizatory (Appium Inspector).
* **Blok 5-8:** Skrypty automatyczne, Page Object Model (POM), Gesty.
* **Blok 9:** Testowanie API dla Mobile (Requests, walidacja JSON).
* **Blok 10:** CI/CD Pipeline oraz Raportowanie Allure.
